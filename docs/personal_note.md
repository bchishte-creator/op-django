## “Part 3 adds an HTTP API 

alongside the website. It exposes resources like food events, foods, people, and categories as endpoints. Django REST Framework maps HTTP methods to create, read, update, and delete operations, validates the incoming data with serializers, and uses the same Django ORM and database as the website. The endpoints are documented in our API guide. Authentication is intentionally omitted for the training exercise, so we need to add access controls before public deployment.”
